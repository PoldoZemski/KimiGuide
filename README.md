# KimiGuide

Пошаговый гайд по экосистеме Kimi от компании Moonshot AI: чат, настольный агент Kimi Work, инструменты программирования Kimi Code и API. Гайд написан как запасной контур на случай блокировки привычных ИИ-сервисов: он ведет от регистрации до рабочих сценариев и заканчивается проверенной на практике процедурой переноса рабочего контура между сервисами.

Гайд собран из рабочей системы и написан для человека, который никогда не пользовался инструментами ИИ: он дает готовые команды и запросы, объясняет, что они делают, и называет риски после каждого блока.

## Что вы получите

- Понимание всей линейки Kimi одной картой: чат, Deep Research, OK Computer, Kimi Work, Kimi Code, Kimi Claw, API и открытые веса.
- Рабочий аккаунт с оплатой из России: проверенный способ оплаты картой Мир и запасные варианты.
- Настольного агента Kimi Work, который читает ваши папки, управляет браузером и выполняет задачи по расписанию, с управлением с телефона через Remote control.
- Агента программирования Kimi Code в терминале и подключение модели Kimi к привычным инструментам: VS Code, Claude Code, Cursor, Roo Code, OpenClaw.
- Готовые сценарии для личной работы и для бизнеса с запросами, которые можно копировать.
- План Б: переносимый контекст в файлах и пошаговая процедура переезда, проверенная на реальном переносе рабочего контура за два дня.

## Для кого

Для тех, кто никогда не пользовался инструментами ИИ или привык к одному сервису и хочет запасной путь. Программировать не нужно. Для глав про терминал нужно уметь три вещи: открыть командную строку, вставить команду, нажать Enter.

## Статус материалов

Главы 00-04 и 07-11 помечены автором как «проверено».

Главы 05 (первый запуск чата), 06 (Kimi Work) и 12 (план Б) имеют статус «в работе»: они собраны из рабочей системы, но финальную вычитку автор не закончил. Идите по ним по шагам и сверяйте результат со своим экраном. Если расходится, остановитесь и разберитесь, прежде чем идти дальше.

Цены, лимиты и состав продуктов приведены на ноябрь 2026 года и меняются быстро. Перед оплатой сверяйтесь с официальными страницами Kimi.

## Как пользоваться

Гайд рассчитан на то, что вы читаете главы прямо на GitHub или кладете их файлами в свои заметки: это обычный markdown. Пометки в шагах: [браузер] - шаг на сайте, [windows] и [mac] - шаг в командной строке, [телефон] - шаг в мобильном приложении.

Ключи API, пароли и реквизиты карт не отправляйте в чат с ИИ и не публикуйте. Полные правила: [глава 11](guide/11-%D0%B1%D0%B5%D0%B7%D0%BE%D0%BF%D0%B0%D1%81%D0%BD%D0%BE%D1%81%D1%82%D1%8C%20%D0%B8%20%D0%B4%D0%B0%D0%BD%D0%BD%D1%8B%D0%B5.md).
