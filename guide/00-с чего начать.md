# 00. С чего начать

Эта серия заметок описывает экосистему Kimi от компании Moonshot AI: чат, настольного агента, инструменты для программирования и API. Начните здесь.

## Для кого

Для человека, который никогда не пользовался инструментами ИИ. Программировать не нужно. Для глав про терминал нужно уметь три вещи: открыть командную строку, вставить команду, нажать Enter. Незнакомые слова собраны в [02-экосистема kimi простыми словами](02-%D1%8D%D0%BA%D0%BE%D1%81%D0%B8%D1%81%D1%82%D0%B5%D0%BC%D0%B0%20kimi%20%D0%BF%D1%80%D0%BE%D1%81%D1%82%D1%8B%D0%BC%D0%B8%20%D1%81%D0%BB%D0%BE%D0%B2%D0%B0%D0%BC%D0%B8.md) и в словарике в конце каждой главы.

## Чего этот гайд не делает

- Не рекламирует Kimi. Ограничения и риски собраны в [11-безопасность и данные](11-%D0%B1%D0%B5%D0%B7%D0%BE%D0%BF%D0%B0%D1%81%D0%BD%D0%BE%D1%81%D1%82%D1%8C%20%D0%B8%20%D0%B4%D0%B0%D0%BD%D0%BD%D1%8B%D0%B5.md).
- Не заменяет официальную документацию. Там, где нужна документация, дана ссылка.

## Пометки в шагах

- [браузер]: шаг выполняется на сайте.
- [windows]: шаг для командной строки Windows.
- [mac]: шаг для терминала macOS.
- [телефон]: шаг выполняется в мобильном приложении.

## Правила безопасности для новичка

1. Не отправляйте в чат с ИИ пароли, ключи, реквизиты карт и паспортные данные.
2. Не давайте агенту доступ к папке с чувствительными документами без необходимости.
3. Оставляйте включенным режим «спрашивать перед действием»: агент спросит разрешения перед изменением файлов.
4. Проверяйте факты из ответов ИИ перед решениями. ИИ уверенно ошибается.
