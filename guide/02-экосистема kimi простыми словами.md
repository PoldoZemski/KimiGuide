# 02. Экосистема Kimi простыми словами

Эта глава показывает все продукты Kimi одной картой. Прочитайте ее первой и возвращайтесь, когда встретите незнакомое название.

## Одна компания, одна модель, несколько дверей

Представьте электростанцию и розетки. Электростанция одна: это модель Kimi K3.1 Pro, большая нейросеть компании Moonshot AI. Розеток много: чат в браузере, приложение на телефоне, настольная программа, инструмент для программистов, API для компаний. Из каждой розетки идет один и тот же ток.

Это важно понять сразу: когда вы читаете про «Kimi Chat», «Kimi Work» и «Kimi Code», это не три разных ИИ. Это три способа пользоваться одним ИИ.

## Карта продуктов

| Продукт | Что это | Кому нужен | Где работает |
| --- | --- | --- | --- |
| Kimi Chat | Чат с моделью: вопросы, тексты, файлы, поиск | Всем | Браузер, Windows, macOS, iOS, Android |
| Deep Research | Режим чата: сам ищет источники и пишет отчет | Кто готовит аналитику | Внутри чата |
| OK Computer | Агентный режим чата: собирает сайты и презентации из нескольких шагов | Кто делает материалы | Внутри чата |
| Мастера контента чата | Отдельные разделы чата: Слайды, Документы, Таблицы, Дизайн, 3D Make | Кто делает материалы регулярно | Внутри чата |
| Kimi Work | Настольный агент: работает с вашими файлами, браузером и задачами по расписанию | Кто хочет «сотрудника» на компьютере | Windows, macOS на чипах Apple |
| Kimi Code | Агент программирования в терминале и редакторе кода | Разработчикам | Windows, macOS, Linux |
| Kimi Code Desktop | Графическая версия Kimi Code: панель файлов, терминал, браузер внутри | Разработчикам без терминала | Windows, macOS, Linux |
| Kimi CLI | Старая версия Kimi Code на Python | Никому, сворачивается | Заменена на Kimi Code |
| Kimi Claw | Облачный агент, работает круглосуточно без вашего компьютера | Кто хочет задачи 24 на 7 | Облако Kimi |
| Расширение для браузера | Дает агенту управлять вашим браузером | Пользователям Kimi Work | Chrome и Edge |
| Kimi API | Доступ к модели для своих программ | Компаниям и разработчикам | platform.kimi.ai |
| Открытые веса | Сама модель для запуска на своем оборудовании | Крупным командам | Hugging Face |

## Где живут ваши данные

Продукты делятся на два лагеря. Облачные: чат, его мастера контента, Kimi Claw и API, данные лежат на серверах Moonshot и синхронизируются между устройствами. Локальные: Kimi Work, Kimi Code и расширение для браузера, файлы остаются на вашем компьютере, в облако уходит только текст запросов к модели. Подробные таблицы в [05-первый запуск kimi чат](05-%D0%BF%D0%B5%D1%80%D0%B2%D1%8B%D0%B9%20%D0%B7%D0%B0%D0%BF%D1%83%D1%81%D0%BA%20kimi%20%D1%87%D0%B0%D1%82.md) и [06-kimi work настольный агент](06-kimi%20work%20%D0%BD%D0%B0%D1%81%D1%82%D0%BE%D0%BB%D1%8C%D0%BD%D1%8B%D0%B9%20%D0%B0%D0%B3%D0%B5%D0%BD%D1%82.md).

## Словарик

- Модель: сама нейросеть, «мозг» сервиса.
- Токен: кусочек текста, единица измерения работы модели. Одна страница текста это примерно 500-700 токенов.
- Контекст: объем текста, который модель помнит внутри одного разговора. У K3.1 Pro это 1 миллион токенов, примерно 700 тысяч слов.
- Агент: режим, в котором модель не только отвечает, но и действует: открывает файлы, ходит по сайтам, запускает программы.
- API: программная дверца в модель для других программ.
- Открытые веса: файлы модели, которые можно скачать и запустить на своем оборудовании.
