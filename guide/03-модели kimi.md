# 03. Модели Kimi

Эта глава разбирает линейку моделей Kimi: что актуально, что устарело и какую модель выбирать.

## Коротко

На ноябрь 2026 года актуальная модель одна: Kimi K3.1 Pro, релиз 23.10.2026. Она работает везде: в чате, в Kimi Work, в Kimi Code и в API. Все модели серии K2 выводятся из эксплуатации: для новых пользователей они закрыты с 31.10.2026, полный вывод запланирован на конец декабря 2026.

Практический вывод: не запоминайте имена старых моделей. Пользуйтесь той, что стоит по умолчанию.

## Характеристики K3.1 Pro

| Характеристика | Значение |
| --- | --- |
| Размер | 2,8 трлн параметров, активны 104 млрд на токен |

| Контекст | 1 048 576 токенов |

| Уровни рассуждения | low, high, max; по умолчанию max |

Цены в API за миллион токенов: вход 2 доллара, выход 10 долларов, кэшированный вход 0,20 доллара. Highspeed: 4 и 20 долларов. Это на треть дешевле предыдущей K3. Для сравнения: Claude Opus стоит заметно дороже на выходе.

## Уровни рассуждения простыми словами

Уровень рассуждения это глубина обдумывания ответа. Модель «думает» дольше и тратит больше токенов, но отвечает точнее.

| Уровень | Когда выбирать |
| --- | --- |
| low | Быстрые вопросы, пакетные задачи, черновики |
| high | Повседневная работа, основной режим |
| max | Длинные агентные задачи, сложная отладка, многочасовые прогоны |

Важная деталь из документации Kimi Code: смена уровня в середине сессии сбрасывает кэш контекста и делает сессию дороже. Выбирайте уровень на сессию и не переключайте его туда-сюда.

## Насколько сильна модель

По независимому индексу Artificial Analysis на 23.10.2026 K3.1 Pro занимает 4-е место из всех моделей с оценкой 55,1. Впереди Claude Opus 5.5, Claude Sonnet 5.5 и Muse Wonder Full. На тесте Terminal-Bench 4.0, который проверяет работу агента в терминале, независимый замер дал 67 процентов: лучший результат среди всех проверенных моделей.

Держите в голове два предостережения:

1. Часть бенчмарков публикует сама Moonshot на своих задачах и своих настройках. Это не независимая проверка.
2. По галлюцинациям цифры расходятся. Moonshot заявляет падение доли ошибок с 23,4 до 8,3 процента на своем внутреннем тесте. Независимый замер Artificial Analysis дал снижение с 53 до 44 процентов.
