# 05. Первый запуск Kimi Chat

Эта глава проводит вас от регистрации до первых полезных результатов. Все шаги выполняются в браузере, установка не нужна.

## Шаг 1. Регистрация

1. [браузер] Откройте kimi.com.
2. [браузер] Нажмите кнопку входа и выберите регистрацию по электронной почте.
3. [браузер] Введите адрес почты и код из письма.
4. [браузер] Если сайт не открылся, попробуйте другую сеть или мобильное приложение: у части российских провайдеров бывают сбои. Подробнее в [04-тарифы и оплата из россии](04-%D1%82%D0%B0%D1%80%D0%B8%D1%84%D1%8B%20%D0%B8%20%D0%BE%D0%BF%D0%BB%D0%B0%D1%82%D0%B0%20%D0%B8%D0%B7%20%D1%80%D0%BE%D1%81%D1%81%D0%B8%D0%B8.md).

## Шаг 2. Осмотритесь в интерфейсе

В чате есть четыре режима работы. Их переключают кнопки рядом с полем ввода:

| Режим | Что делает | Когда применять |
| --- | --- | --- |
| Instant | Быстрый ответ | Простые вопросы, переводы, переписывание |
| Thinking | Ответ с обдумыванием | Анализ, расчеты, дилеммы |
| Agent | Модель сама выполняет шаги и пользуется инструментами | Многоэтапные задачи |
| Agent Swarm | Несколько агентов работают параллельно | Широкие исследования, платные планы |

## Шаг 3. Задайте первый вопрос

Начните с рабочей задачи, а не с теста «как дела». Хороший первый запрос для финансиста:

> Прочитай приложенный управленческий отчет. Назови три места, где цифры выглядят необычно, и задай мне вопросы, которые помогут понять причину.

Прикрепите файл значком скрепки рядом с полем ввода. Kimi читает PDF, Word, Excel и картинки.

ПРИМЕЧАНИЕ: кнопка микрофона рядом с полем ввода включает голосовой ввод. Если она распознает речь не на том языке, используйте диктовку системы. В Windows нажмите Win+H, на Mac дважды нажмите Fn. Подробности в [06-kimi work настольный агент](06-kimi%20work%20%D0%BD%D0%B0%D1%81%D1%82%D0%BE%D0%BB%D1%8C%D0%BD%D1%8B%D0%B9%20%D0%B0%D0%B3%D0%B5%D0%BD%D1%82.md).

## Шаг 4. Попробуйте Deep Research

Deep Research это режим самостоятельного исследования. Модель ходит по источникам, сверяет факты и собирает структурированный отчет со ссылками.

Пример запроса:

> Собери обзор рынка управленческого учета для малого бизнеса в России за 2026 год. Дай цифры только со ссылками на источники. Отдельно отметь утверждения, которые подтвердить не удалось.

Проверьте отчет по ссылкам. Deep Research экономит часы поиска, но не отменяет проверку ключевых фактов.

## Шаг 5. Попробуйте OK Computer

OK Computer это агентный режим, который собирает многошаговые результаты: презентации, страницы, документы.

Пример запроса:

> Собери презентацию на 8 слайдов для собственника бизнеса: зачем ему управленческий учет и с чего начать. Тон спокойный, без рекламы.

Результат можно отредактировать и выгрузить. В Kimi Work исследование превращается в файл PowerPoint или Excel напрямую, см. [06-kimi work настольный агент](06-kimi%20work%20%D0%BD%D0%B0%D1%81%D1%82%D0%BE%D0%BB%D1%8C%D0%BD%D1%8B%D0%B9%20%D0%B0%D0%B3%D0%B5%D0%BD%D1%82.md).

## Шаг 6. Установите приложение на телефон

1. [телефон] Установите Kimi из App Store или Google Play. Проверьте издателя: Moonshot AI.
2. [телефон] Войдите в тот же аккаунт.
3. [телефон] Диалоги чата синхронизируются между браузером, компьютером и телефоном. Диалоги режима Work остаются на компьютере.

## Разделы боковой панели

Слева в чате расположены разделы. Вот что стоит за каждым. Состав разделов меняется быстро, пометки New и Beta в интерфейсе означают, что раздел новый или тестовый.

| Раздел | Что это | Когда открывать |
| --- | --- | --- |
| Мой Kimi | Ваш основной чат и персональная зона аккаунта | Ежедневная работа |
| Плагины | Подключение внешних сервисов к чату | Когда нужны данные из стороннего сервиса |
| Задачи по расписанию | Регулярные задания чата: сводки, мониторинг | Утренние сводки, еженедельные отчеты |
| Вдохновение | Подборка примеров запросов и сценариев | Когда не знаете, с чего начать |
| Слайды | Генерация презентаций из текста | Подготовка выступления или КП |
| 3D Make | Генерация 3D-моделей, раздел новый | Визуализация изделий, прототипы |
| Глубокое исследование | То же, что Deep Research из шага 4 | Аналитика со ссылками на источники |
| Создать приложение | То же, что OK Computer из шага 5: сайт или приложение по описанию | Лендинг, простой сервис, прототип |
| Документы | Создание и редактирование документов Word и PDF | Отчеты, договоры-шаблоны, тексты |
| Таблицы | Генерация и разбор таблиц Excel | Модели, выгрузки, сводные |
| Дизайн | Генерация и редактирование изображений, статус Beta | Иллюстрации, обложки, баннеры |
| Kimi Code | Вход в среду программирования | Разработка, см. [07-kimi code в терминале](07-kimi%20code%20%D0%B2%20%D1%82%D0%B5%D1%80%D0%BC%D0%B8%D0%BD%D0%B0%D0%BB%D0%B5.md) |
| Kimi Claw | Облачный агент, работает круглосуточно | Задачи 24 на 7, см. [02-экосистема kimi простыми словами](02-%D1%8D%D0%BA%D0%BE%D1%81%D0%B8%D1%81%D1%82%D0%B5%D0%BC%D0%B0%20kimi%20%D0%BF%D1%80%D0%BE%D1%81%D1%82%D1%8B%D0%BC%D0%B8%20%D1%81%D0%BB%D0%BE%D0%B2%D0%B0%D0%BC%D0%B8.md) |
| Платформа Kimi | Консоль API для разработчиков | Подключение модели к своим программам, см. [10-kimi для бизнеса](10-kimi%20%D0%B4%D0%BB%D1%8F%20%D0%B1%D0%B8%D0%B7%D0%BD%D0%B5%D1%81%D0%B0.md) |

ПРИМЕЧАНИЕ: назначение разделов «Мой Kimi» и «Вдохновение» описано по состоянию интерфейса на ноябрь 2026 и может отличаться в вашей версии. Проверьте на своем экране.

## Проекты в Kimi Chat

Ниже раздела Kimi Claw в боковой панели находится блок «Проекты». Проект в чате это облачный контейнер: внутри лежат чаты проекта, инструкции проекта и приложенные файлы.

1. Создание: кнопка «+» рядом со словом «Проекты». Задайте имя и при желании инструкции: они действуют на все чаты внутри проекта.
2. Страница проекта: слева чаты проекта, справа блоки «Инструкции» и «Файлы».
3. Применение: заведите проект на каждого клиента или направление. Инструкции вида «отвечай в терминах управленческого учета» перестанут повторяться в каждом чате.
4. Осторожно: удаление проекта стирает его чаты, файлы и инструкции безвозвратно.

Проекты чата это часть вашего переносимого контекста. Как не потерять их при блокировке, написано в [12-план б на случай блокировки](12-%D0%BF%D0%BB%D0%B0%D0%BD%20%D0%B1%20%D0%BD%D0%B0%20%D1%81%D0%BB%D1%83%D1%87%D0%B0%D0%B9%20%D0%B1%D0%BB%D0%BE%D0%BA%D0%B8%D1%80%D0%BE%D0%B2%D0%BA%D0%B8.md).

## Где хранятся данные

Это ключевое различие двух продуктов. Запомните его до начала работы.

| | Kimi Chat | Kimi Work |
| --- | --- | --- |
| Чаты | Облако Moonshot | На вашем компьютере |
| Файлы и проекты | Облако Moonshot | Ваши локальные папки |
| Синхронизация между устройствами | Да | Нет, только через Remote control |
| Что уходит в облако | Весь диалог | Только текст запросов к модели |

Чат удобен синхронизацией: начали на компьютере, продолжили на телефоне. Цена удобства: все материалы живут на серверах Moonshot. Work наоборот: файлы не покидают компьютер, но и открыть их с телефона нельзя, кроме как через удаленное управление, см. [06-kimi work настольный агент](06-kimi%20work%20%D0%BD%D0%B0%D1%81%D1%82%D0%BE%D0%BB%D1%8C%D0%BD%D1%8B%D0%B9%20%D0%B0%D0%B3%D0%B5%D0%BD%D1%82.md). Юридическая сторона вопроса разобрана в [11-безопасность и данные](11-%D0%B1%D0%B5%D0%B7%D0%BE%D0%BF%D0%B0%D1%81%D0%BD%D0%BE%D1%81%D1%82%D1%8C%20%D0%B8%20%D0%B4%D0%B0%D0%BD%D0%BD%D1%8B%D0%B5.md).

## Пять привычек, которые окупаются сразу

1. Пишите задачу, а не вопрос: «сделай таблицу» вместо «как сделать таблицу».
2. Давайте контекст: кто читатель, зачем документ, какие ограничения.
3. Просите показать неуверенность: «отметь, что ты предположил, а что нашел».
4. Разбивайте большую задачу на две-три подряд, а не одну гигантскую.
5. Сохраняйте удачные формулировки запросов в заметки: это ваш переносимый контекст, см. [12-план б на случай блокировки](12-%D0%BF%D0%BB%D0%B0%D0%BD%20%D0%B1%20%D0%BD%D0%B0%20%D1%81%D0%BB%D1%83%D1%87%D0%B0%D0%B9%20%D0%B1%D0%BB%D0%BE%D0%BA%D0%B8%D1%80%D0%BE%D0%B2%D0%BA%D0%B8.md).
