# 06. Kimi Work: настольный агент

Эта глава описывает Kimi Work: настольное приложение, которое работает с вашими файлами, браузером и задачами по расписанию.

## Что это такое

Обычный чат живет в облаке: вы отправляете текст, сервер отвечает. Kimi Work устроен наоборот. Программа стоит на вашем компьютере и действует на нем: читает папки, которые вы разрешили, открывает ваш браузер, запускает расчеты, собирает файлы. Модель при этом работает в облаке Moonshot: «руки» у вас, «мозг» на сервере.

Аналогия: чат это консультант по телефону, Kimi Work это ассистент, которого вы пустили в свой кабинет.

## Что умеет

| Возможность | Пример задачи |
| --- | --- |
| Локальные файлы | «Разбери папку с отчетами за квартал и собери сводную таблицу» |
| Браузерный агент | «Открой эти десять сайтов и выпиши цены конкурентов в таблицу» |
| Задачи по расписанию | «Каждое утро в 8:00 собирай новости по моим темам в один файл» |
| Agent Swarm | Большая задача делится между субагентами, до 300 параллельно на старших планах |
| Рыночные данные | Акции Китая, Гонконга и США уже подключены, настройка API не нужна |
| Экспорт | Исследование превращается в PowerPoint, PDF или Excel |

## Установка

1. [браузер] Откройте kimi.com и перейдите на страницу загрузки.
2. [браузер] Скачайте версию для вашей системы. Поддерживаются Windows и macOS на чипах Apple. На Mac с процессором Intel доступен только чат без агентных функций.
3. [браузер] Установите приложение и войдите в свой аккаунт Kimi.
4. Агентные функции требуют платного плана, см. [04-тарифы и оплата из россии](04-%D1%82%D0%B0%D1%80%D0%B8%D1%84%D1%8B%20%D0%B8%20%D0%BE%D0%BF%D0%BB%D0%B0%D1%82%D0%B0%20%D0%B8%D0%B7%20%D1%80%D0%BE%D1%81%D1%81%D0%B8%D0%B8.md).

## Разделы приложения

В левой панели Kimi Work находятся основные разделы:

| Раздел | Что это |
| --- | --- |
| Разговоры | Список сессий с агентом, как чаты, только на компьютере |
| Проекты | Рабочие области с привязкой к папкам компьютера, подробно ниже |
| Дашборд | Постоянный экран из виджетов: агент собирает интерактивные страницы с данными, а дашборд группирует их по теме или проекту |
| Центр задач | Управление задачами по расписанию и целями: создание, правка, включение и пауза, история запусков |
| Плагины | Подключение внешних сервисов и баз данных к агенту, плюс навыки: готовые процедуры работы, свои и загруженные |
| Apps | Мини-приложения и сайты, которые агент собрал по вашим задачам |
| Remote control | Управление этим компьютером с телефона, подробно ниже |

ПРИМЕЧАНИЕ: состав разделов меняется от версии к версии. Если в вашем приложении раздел называется иначе, ориентируйтесь по смыслу таблицы.

## Голосовой ввод и диктовка

Кнопка микрофона рядом с полем ввода записывает речь и превращает ее в текст запроса. Распознавание идет на сервере Moonshot, и сервис сам определяет язык речи. Настройки языка распознавания в приложении нет.

Известная проблема: кнопка микрофона иногда распознает русскую речь как китайский или английский текст. Если вы столкнулись с этим, используйте диктовку операционной системы. Она работает в любом поле ввода, в том числе в поле чата Kimi.

Диктовка в Windows:

1. Поставьте курсор в поле ввода.
2. Нажмите Win+H. Начнется запись речи.
3. Говорите текст. Нажмите Esc или значок микрофона, чтобы закончить.

Диктовка в macOS:

1. Откройте «Системные настройки», выберите «Клавиатура», затем «Диктовка».
2. Включите диктовку и добавьте русский язык.
3. Поставьте курсор в поле ввода.
4. Дважды нажмите клавишу Fn с символом глобуса.
5. Говорите текст.

На новых MacBook запускает диктовку и клавиша микрофона F5. На Mac с чипом Apple диктовка работает на устройстве и не требует сети.

ПРИМЕЧАНИЕ: диктовка macOS выключается после 30 секунд паузы. Нажмите клавишу диктовки снова, чтобы продолжить.

Сторонние программы для диктовки:

| Программа | Системы | Офлайн | Цена |
| --- | --- | --- | --- |
| Handy | Windows, Mac, Linux | да | бесплатно, открытый код |
| Wispr Flow | Windows, Mac, iOS, Android | нет | 2000 слов в неделю бесплатно, далее $12-15 в месяц |
| Superwhisper | Mac | да | бесплатный уровень, далее $8,5 в месяц |
| VoiceInk | Mac | да | разовая покупка $25-29, открытый код |
| Aqua Voice | Windows, Mac, iOS, Android | нет | 1000 слов бесплатно, далее $8-10 в месяц |
| Spokenly | Windows, Mac | да | есть бесплатный уровень |

Все программы из таблицы распознают русский язык. Встроенной диктовки системы хватает для разовых задач. Сторонняя программа окупается, если вы диктуете ежедневно. Отдельная ниша: Google Docs распознает речь внутри документа, бесплатно и только в Chrome.

## Проекты в Kimi Work

Проект в Kimi Work это постоянная рабочая область: набор разговоров агента, привязанный к конкретной папке на вашем компьютере.

1. При создании проекта вы выбираете папку. Все файлы, с которыми работает агент в этом проекте, лежат в ней: и ваши исходники, и результаты.
2. Проект помнит контекст: инструкции, настройки и историю разговоров. Новый разговор внутри проекта продолжает работу, а не начинает с нуля.
3. Заводите проект на каждое устойчивое направление: клиент, продукт, хранилище заметок. Одна папка - один проект.

Чем проект Work отличается от проекта чата. В Kimi Chat проект это облачный контейнер: чаты, инструкции и файлы лежат на серверах Moonshot. В Kimi Work проект привязан к локальной папке, и файлы остаются у вас. Это две разные системы: они не связаны между собой и не передают друг другу данные. Проекты чата описаны в [05-первый запуск kimi чат](05-%D0%BF%D0%B5%D1%80%D0%B2%D1%8B%D0%B9%20%D0%B7%D0%B0%D0%BF%D1%83%D1%81%D0%BA%20kimi%20%D1%87%D0%B0%D1%82.md).

## Remote control: управление с телефона

Remote control это режим, в котором телефон становится окном в Kimi Work на вашем компьютере. Задачи всегда выполняются на компьютере: файлы, входы в сервисы и настройки остаются на нем. Телефон только показывает ход работы и принимает команды.

Что можно делать с телефона:

1. Запускать новые задачи: написать поручение в дороге, а выполнится оно на компьютере с вашими файлами.
2. Следить за ходом работы в реальном времени: шаги, инструменты, результаты.
3. Подтверждать или отклонять запросы агента: доступ к папке, отправка письма, запуск команды. Запрос приходит одновременно на компьютер и на телефон, задача не встает в ожидании.
4. Дописывать указания на ходу: сообщения встают в очередь или сразу корректируют задачу.
5. Переключаться между несколькими подключенными компьютерами.

Подключение в три шага:

1. [компьютер] В Kimi Work откройте раздел Remote control в левой панели и включите «Разрешить управление с телефона».
2. [телефон] Установите приложение Kimi версии 3.1.0 или новее и войдите в тот же аккаунт.
3. [телефон] Откройте Remote control в приложении, выберите «Добавить устройство» и подтвердите подключение на компьютере.

Условия работы: компьютер включен, не спит и подключен к сети, приложение Kimi Work запущено. Закрытый ноутбук недоступен с телефона.

## Первое подключение папки

1. Откройте настройки рабочей области в Kimi Work.
2. Подключите одну тестовую папку, не рабочий архив. Создайте папку специально для экспериментов.
3. Оставьте включенным режим «спрашивать перед действием»: агент запросит разрешение перед изменением файлов и запуском кода.
4. Дайте первую задачу с безопасным результатом: «Прочитай файлы в папке и составь список документов с датами».

ПРИМЕЧАНИЕ: не подключайте папки с договорами, персональными данными и финансовыми документами клиентов. Причины в [11-безопасность и данные](11-%D0%B1%D0%B5%D0%B7%D0%BE%D0%BF%D0%B0%D1%81%D0%BD%D0%BE%D1%81%D1%82%D1%8C%20%D0%B8%20%D0%B4%D0%B0%D0%BD%D0%BD%D1%8B%D0%B5.md).

## Браузерный агент

Расширение WebBridge позволяет Kimi управлять вашим настоящим браузером Chrome или Edge: открывать вкладки, нажимать кнопки, забирать данные со страниц, где вы уже вошли в аккаунт.

Это сильная и одновременно чувствительная функция. Браузер знает ваши входы в почту, банк и рабочие сервисы. Правила:

1. Давайте браузерные задачи только с понятной целью.
2. Не оставляйте агента работать с банковскими и платежными страницами.
3. Проверяйте итог перед отправкой или оплатой чего-либо.

## Задачи по расписанию

Встроенный планировщик запускает задачи по расписанию: каждый день, каждую неделю, каждый месяц или один раз. Управляется через Центр задач. Типичные применения:

- утренняя сводка новостей по вашим темам;
- еженедельный сбор показателей из подключенных источников;
- регулярная проверка изменений на сайтах конкурентов.

Задачи выполняются локально и только пока приложение открыто, а компьютер не спит. Пропущенный запуск не догоняется задним числом. Для ночных задач включите в настройках режим «не давать компьютеру уснуть». Если нужна работа круглосуточно без вашего компьютера, смотрите облачный Kimi Claw в [02-экосистема kimi простыми словами](02-%D1%8D%D0%BA%D0%BE%D1%81%D0%B8%D1%81%D1%82%D0%B5%D0%BC%D0%B0%20kimi%20%D0%BF%D1%80%D0%BE%D1%81%D1%82%D1%8B%D0%BC%D0%B8%20%D1%81%D0%BB%D0%BE%D0%B2%D0%B0%D0%BC%D0%B8.md).

## Где хранятся данные

| | Kimi Work | Kimi Chat |
| --- | --- | --- |
| Разговоры и проекты | На вашем компьютере | Облако Moonshot |
| Файлы | Ваши локальные папки | Облако Moonshot |
| В облако уходит | Текст запросов к модели | Весь диалог и файлы |

Это главный аргумент за Work для рабочих материалов. Обратная сторона: разговоры Work не синхронизируются между устройствами, с телефона они доступны только через Remote control. Подробнее в таблице различий в [05-первый запуск kimi чат](05-%D0%BF%D0%B5%D1%80%D0%B2%D1%8B%D0%B9%20%D0%B7%D0%B0%D0%BF%D1%83%D1%81%D0%BA%20kimi%20%D1%87%D0%B0%D1%82.md) и о рисках в [11-безопасность и данные](11-%D0%B1%D0%B5%D0%B7%D0%BE%D0%BF%D0%B0%D1%81%D0%BD%D0%BE%D1%81%D1%82%D1%8C%20%D0%B8%20%D0%B4%D0%B0%D0%BD%D0%BD%D1%8B%D0%B5.md).

## Словарик

- Субагент: помощник, которого главный агент запускает для части задачи.
- Cron: стандартное расписание вида «каждый день в 8:00».
- Рабочая область: папка или набор папок, к которым у агента есть доступ.
- Виджет: интерактивная страница с данными, которую агент собирает и обновляет.
- Цель: длительная задача с критериями результата, которую агент ведет в несколько подходов.
