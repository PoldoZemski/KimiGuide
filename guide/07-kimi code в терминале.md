# 07. Kimi Code в терминале

Эта глава устанавливает и запускает Kimi Code: агента программирования, который живет в командной строке. Глава написана для человека, который никогда не работал в терминале. Команды даны для копирования: скопируйте строку целиком и вставьте в терминал.

## Что это такое

Kimi Code это программа, которая читает папку с вашим проектом и выполняет задачи: пишет и правит код, запускает проверки, ищет ошибки. Вы описываете задачу обычными словами, агент делает шаги сам и показывает, что меняет.

Репозиторий проекта: github.com/MoonshotAI/kimi-code. Лицензия MIT, код открыт. Первая версия вышла в мае 2026, продукт молодой: обновления выходят несколько раз в неделю.

ПРИМЕЧАНИЕ: был старый инструмент Kimi CLI на Python, он сворачивается. Если инструкция в интернете говорит выполнить `pip install kimi-cli`, это устаревший вариант. Новый Kimi Code сам переносит настройки старого: выполните `kimi migrate`.

## Где хранятся данные

Код и файлы проекта остаются на вашем компьютере: агент работает с локальной папкой. Файл AGENTS.md с правилами проекта лежит в самом проекте, сессии и настройки хранятся локально. В облако Moonshot уходит только контекст запросов к модели: фрагменты кода, которые агент считает нужными для ответа. Ключ API хранится в локальном конфиге, никому его не пересылайте. Это тот же принцип, что у Kimi Work, см. таблицу в [06-kimi work настольный агент](06-kimi%20work%20%D0%BD%D0%B0%D1%81%D1%82%D0%BE%D0%BB%D1%8C%D0%BD%D1%8B%D0%B9%20%D0%B0%D0%B3%D0%B5%D0%BD%D1%82.md).

## Графическая версия: Kimi Code Desktop

У Kimi Code есть настольное приложение с графическим интерфейсом: то же агентное ядро плюс панель файлов, просмотр изменений в коде, встроенный терминал и браузер. Внутри доступны режимы Plan, Goal и Swarm. Открыть страницу приложения можно из терминала командами `kimi install-app` или `/desktop`. Поддерживаются Windows, macOS и Linux.

Если терминал вам не подошел после этой главы, Desktop это способ получить того же агента в привычном окне. Удаленное управление с телефона в экосистеме Kimi описано в [06-kimi work настольный агент](06-kimi%20work%20%D0%BD%D0%B0%D1%81%D1%82%D0%BE%D0%BB%D1%8C%D0%BD%D1%8B%D0%B9%20%D0%B0%D0%B3%D0%B5%D0%BD%D1%82.md).

## Шаг 0. Откройте терминал

[windows] Нажмите клавишу Win, наберите `PowerShell`, нажмите Enter.

[mac] Нажмите Cmd и пробел, наберите `Terminal`, нажмите Enter.

### Как вставлять текст в терминал

Вставка в терминале отличается от привычной:

- [windows] В PowerShell сочетание Ctrl+V часто не работает. Используйте Ctrl+Shift+V или щелчок правой кнопкой мыши.
- [windows] В новых версиях Windows Terminal работает и Ctrl+V: зависит от настроек. Если вставка не сработала, попробуйте правую кнопку мыши.
- [mac] Вставка обычная: Cmd+V.

Проверьте себя: скопируйте слово `kimi` и вставьте его в терминал. Получилось - двигайтесь дальше.

## Шаг 1. Установите Kimi Code

Выберите один способ.

### Способ А: установочный скрипт, рекомендуется

[windows] В PowerShell выполните:

```powershell
irm https://code.kimi.com/kimi-code/install.ps1 | iex
```

[mac] В терминале выполните:

```bash
curl -fsSL https://code.kimi.com/kimi-code/install.sh | bash
```

Этот способ ставит один самодостаточный файл программы и не требует ничего еще.

### Способ Б: через npm

Если у вас уже установлен Node.js версии 22.19.0 или новее:

```bash
npm install -g @moonshot-ai/kimi-code
```

Проверить версию Node.js: `node --version`.

### Особенность для Windows

На Windows Kimi Code требует установленный Git for Windows с сайта git-scm.com. Если при запуске видите ошибку про Git или shell, установите Git и перезапустите терминал. Путь к Git Bash при нестандартной установке задается переменной окружения `KIMI_SHELL_PATH`.

## Шаг 2. Проверьте установку

```bash
kimi --version
```

Терминал должен показать номер версии. Если пишет «команда не найдена»: закройте терминал, откройте заново и повторите. Не помогло - переустановите способом А.

## Шаг 3. Войдите в аккаунт

1. Перейдите в папку любого проекта: `cd путь\к\папке`.
2. Запустите агента: `kimi`.
3. Внутри введите команду `/login`.
4. Выберите способ: Kimi Code через OAuth или ключ API с платформы.

OAuth проще: программа покажет ссылку и код. Откройте ссылку на любом устройстве, войдите в аккаунт Kimi, введите код. Расход пойдет на подписку.

Ключ API берется на platform.kimi.ai и оплачивается по токенам отдельно от подписки, см. [04-тарифы и оплата из россии](04-%D1%82%D0%B0%D1%80%D0%B8%D1%84%D1%8B%20%D0%B8%20%D0%BE%D0%BF%D0%BB%D0%B0%D1%82%D0%B0%20%D0%B8%D0%B7%20%D1%80%D0%BE%D1%81%D1%81%D0%B8%D0%B8.md).

## Шаг 4. Первая задача

Внутри `kimi` пишите обычными словами:

```
> Посмотри структуру этой папки и расскажи, что это за проект
```

Если в проекте еще нет файла AGENTS.md, выполните:

```
> /init
```

Агент изучит проект и запишет файл AGENTS.md с правилами проекта. В следующие разы он будет учитывать их сам.

## Команды, которые стоит знать

| Команда | Что делает |
| --- | --- |
| /help | Список всех команд |
| /model | Сменить модель |
| /new | Новая сессия, чистый контекст |
| /compact | Сжать контекст, когда сессия разрослась |
| /fork | Ответвление сессии: попробовать вариант и вернуться |
| /login и /logout | Вход и выход |
| Ctrl-X | Режим команд системы прямо внутри агента |
| kimi web | Веб-интерфейс в браузере вместо терминала |
| kimi upgrade | Обновить программу |

ПРИМЕЧАНИЕ: в режиме Ctrl-X встроенная команда `cd` не работает. Чтобы сменить папку, выйдите из `kimi`, перейдите в папку и запустите снова.

## Как платится работа

Работа агента расходует либо лимиты подписки, либо токены API. Два рычага экономии:

1. Уровень рассуждения: `high` для повседневных задач, `max` для тяжелых. Смена уровня посередине сессии сбрасывает кэш и удорожает ее, см. [03-модели kimi](03-%D0%BC%D0%BE%D0%B4%D0%B5%D0%BB%D0%B8%20kimi.md).
2. Команда `/compact` на длинных сессиях: меньше контекст, меньше счет.
