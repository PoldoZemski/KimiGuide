# 08. Kimi в инструментах разработки

Эта глава показывает, как подключить модели Kimi к привычным инструментам: VS Code, Cursor, Claude Code, OpenClaw и другим. Она для тех, кто уже работает с ИИ-агентами и хочет сменить или продублировать модель.

## Главная мысль

Инструмент и модель это разные вещи. Claude Code, Cline, Roo Code и OpenClaw это «кабины». Kimi это «двигатель», который встают в большинство таких кабин через два стандартных разъема:

- OpenAI-совместимый API: базовый адрес вида `https://api.moonshot.ai/v1`.
- Anthropic-совместимый API: для инструментов семейства Claude Code.

ПРИМЕЧАНИЕ: у Moonshot идет переезд с домена moonshot.ai на kimi.com. В документации встречаются оба. Если адрес не отвечает, проверьте актуальный в консоли platform.kimi.ai. Точные идентификаторы моделей смотрите командой `/models` в инструменте или в консоли, не в статьях: они меняются.

## VS Code

1. Откройте маркетплейс расширений.
2. Найдите Kimi Code, издатель moonshot-ai.
3. Установите и войдите в аккаунт Kimi.

Интерфейс похож на расширение Claude Code: панель диалога сбоку, операции с кодом по одобрению.

## Claude Code

Claude Code умеет работать с моделью Kimi вместо Claude. Задаются две переменные окружения.

[mac] и Linux:

```bash
export ANTHROPIC_BASE_URL="https://api.moonshot.ai/anthropic"
export ANTHROPIC_AUTH_TOKEN="ваш-ключ-kimi-api"
```

[windows] PowerShell:

```powershell
$env:ANTHROPIC_BASE_URL="https://api.moonshot.ai/anthropic"
$env:ANTHROPIC_AUTH_TOKEN="ваш-ключ-kimi-api"
```

Затем запустите `claude` и проверьте `/status`. Идентификатор модели задайте по документации Kimi на день настройки: он менялся между k3 и вариантами с суффиксом контекста.

## Roo Code и Cline в VS Code

1. Установите расширение Roo Code или Cline.
2. Откройте настройки провайдера.
3. Выберите OpenAI Compatible.
4. Укажите базовый адрес `https://api.moonshot.ai/v1`, ключ API и идентификатор модели.
5. Проверьте не только ответ в чате, но и задачу с вызовом инструментов: чтением и правкой файлов. Roo Code требует от модели полноценного tool calling, без этого агентный режим не работает.

Roo Code назван на странице поддержки Kimi как совместимый агент. Cline в официальном списке не значится: подключение технически возможно, но проверяйте на своих задачах. Не подделывайте идентификатор клиента под поддерживаемый агент: это нарушение условий и риск блокировки ключа.

## Cursor

В Cursor сторонний API-ключ работает только в режиме Ask: вопросы и ответы про код. Родной агентный режим с внешним ключом недоступен. Если нужен агент внутри Cursor, поставьте в него расширение Cline или Roo Code и подключите Kimi там.

Отдельный факт для понимания рынка: собственную модель Cursor компания строила на базе модели Kimi. Качество двигателя признано не только пользователями, но и конкурентами.

## OpenClaw, Hermes и семейство

OpenClaw, Hermes и похожие рамки принимают любого провайдера с OpenAI-совместимым API. В конфиге провайдера укажите адрес и ключ Kimi и идентификатор модели. Две оговорки:

1. Агентные рамки делают много вызовов инструментов. Проверьте набор своих типовых задач, а не один диалог.
2. Счет за токены на длинных агентных прогонах растет быстро. Начните с уровня рассуждения `high`, см. [03-модели kimi](03-%D0%BC%D0%BE%D0%B4%D0%B5%D0%BB%D0%B8%20kimi.md).

Если не хотите поднимать OpenClaw сами: у Moonshot есть управляемый облачный вариант Kimi Claw с моделью внутри. Он работает круглосуточно и не зависит от вашего компьютера.

## Где хранятся данные при таких подключениях

Во всех схемах этой главы код и файлы проекта остаются на вашем компьютере или вашем сервере. Ключ API Kimi лежит в локальных конфигах инструментов: переменных окружения и файлах настроек. Никому его не пересылайте и не коммитьте в репозиторий.

В облако Moonshot уходит контекст запросов: фрагменты кода и файлов, которые инструмент отправляет модели для ответа. Объем зависит от инструмента: агентные рамки отправляют больше, чем простой чат. Исключение из таблицы: Kimi Claw это облачный агент, его рабочая среда живет на серверах Moonshot. Общая картина размещения данных в [06-kimi work настольный агент](06-kimi%20work%20%D0%BD%D0%B0%D1%81%D1%82%D0%BE%D0%BB%D1%8C%D0%BD%D1%8B%D0%B9%20%D0%B0%D0%B3%D0%B5%D0%BD%D1%82.md), риски в [11-безопасность и данные](11-%D0%B1%D0%B5%D0%B7%D0%BE%D0%BF%D0%B0%D1%81%D0%BD%D0%BE%D1%81%D1%82%D1%8C%20%D0%B8%20%D0%B4%D0%B0%D0%BD%D0%BD%D1%8B%D0%B5.md).

## Что выбрать при переезде с Claude

| Ваша привычка | Куда переходить |
| --- | --- |
| Claude Code в терминале | Оставить Claude Code, сменить модель на Kimi, или поставить Kimi Code |
| Расширение Claude в VS Code | Расширение Kimi Code или Roo Code с Kimi |
| Cursor целиком | Cursor с Kimi в режиме Ask плюс расширение для агентных задач |
| OpenClaw на сервере | Тот же OpenClaw с провайдером Kimi или облачный Kimi Claw |
