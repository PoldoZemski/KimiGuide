# 10. Kimi для бизнеса

Эта глава для тех, кто рассматривает Kimi не для себя лично, а для процессов компании: свои сервисы, автоматизация, команда.

## Три пути для компании

| Путь | Что это | Когда подходит |
| --- | --- | --- |
| Подписки сотрудников | Kimi Chat и Kimi Work по местам | Старт, пилот, до нескольких человек |
| API | Модель встраивается в свои программы и процессы | Автоматизация, свои продукты |
| Открытые веса | Модель на своем оборудовании | Жесткие требования к данным, большие объемы |

## Путь 1. Подписки сотрудников

Простой старт: несколько сотрудников оформляют планы Plus или Pro и применяют Kimi к своим задачам. Управление рабочими пространствами и местами для команд есть в Kimi for Business.

Порядок пилота:

1. Выберите 2-3 задачи с измеримым результатом: подготовка аналитических записок, разбор первичных документов, мониторинг источников.
2. Назначьте владельца пилота.
3. Договоритесь, что в Kimi не загружают: персональные данные клиентов, банковские реквизиты, материалы под NDA.
4. Через месяц измерьте результат в часах и качестве.

## Путь 2. API

Платформа platform.kimi.ai выдает ключи и принимает оплату по токенам. Основные факты:

- Минимальное пополнение 1 доллар.
- Цены K3.1 Pro: 2 доллара за миллион входных токенов, 10 долларов за миллион выходных, кэшированный вход 0,20 доллара. Кэширование повторных кусков контекста включается автоматически и заметно дешевле.
- Два стиля подключения: OpenAI-совместимый и Anthropic-совместимый API. Большинство существующих программ подключается сменой адреса и ключа, см. [08-kimi в инструментах разработки](08-kimi%20%D0%B2%20%D0%B8%D0%BD%D1%81%D1%82%D1%80%D1%83%D0%BC%D0%B5%D0%BD%D1%82%D0%B0%D1%85%20%D1%80%D0%B0%D0%B7%D1%80%D0%B0%D0%B1%D0%BE%D1%82%D0%BA%D0%B8.md).
- Доступен режим Zero Data Retention: запросы не сохраняются на стороне провайдера. Для рабочих процессов компании это базовое требование, включите его до передачи любых деловых данных.

Типичные применения: разбор входящих документов, подготовка ответов клиентам, внутренние справочные боты, обогащение данных.

## Путь 3. Открытые веса

Модель K3 опубликована с открытыми весами на Hugging Face под собственной лицензией Kimi K3 License. Веса K3.1 Pro обещаны к 04.11.2026. Прочитайте лицензию до коммерческого применения: «открытые веса» не равно «свободная лицензия».

Трезвая оценка: модель на 2,8 трлн параметров это дата-центр, а не сервер в офисе. Собственный запуск оправдан при очень больших объемах или жестких требованиях регуляторов. Для большинства компаний правильный ответ это API с Zero Data Retention, а не свое железо.

## Сравнение расходов с привычными инструментами

Kimi позиционируется как сильно более дешевый вариант на уровне API: выходные токены флагманских моделей Anthropic стоят в разы дороже. При этом дешевизна токена не равна дешевизне задачи: модель с активным рассуждением тратит больше токенов на ответ. Считайте стоимость задачи на своих сценариях, а не по прейскуранту.

Порядок оценки:

1. Возьмите 5 типовых задач компании.
2. Прогоните их через API Kimi с замером токенов.
3. Прогоните те же задачи через действующий инструмент.
4. Сравните не только цену, но и качество результата и число переделок.
