# 11. Безопасность и данные

Эта глава о том, что происходит с вашими данными в Kimi и какие правила снижают риск. Прочитайте ее до того, как дадите агенту реальные задачи.

## Куда уходят данные

Модель Kimi работает в облаке Moonshot AI. Сервис оперирует компанией Moonshot AI Pte. Ltd. из Сингапура с операционной структурой в Пекине. Политика конфиденциальности допускает передачу и хранение данных на серверах за пределами вашей страны без указания юрисдикции. По состоянию на середину 2026 года в потребительском продукте нет задокументированной настройки, которая запрещает использование ваших запросов для обучения моделей.

Практический вывод: считайте, что все, что вы отправляете в чат, покидает ваш контроль и попадает под китайское регулирование.

Важная оговорка про «локальность» Kimi Work. Локальны действия: чтение файлов, клики в браузере, запуск программ. Сами запросы к модели все равно уходят в облако. Локальный запуск возможен только с открытыми весами на своем оборудовании, см. [10-kimi для бизнеса](10-kimi%20%D0%B4%D0%BB%D1%8F%20%D0%B1%D0%B8%D0%B7%D0%BD%D0%B5%D1%81%D0%B0.md).

## Что не отправлять

| Категория | Примеры |
| --- | --- |
| Секреты доступа | Пароли, ключи API, токены, реквизиты карт |
| Персональные данные третьих лиц | Документы клиентов, сотрудников, контрагентов |
| Коммерческая тайна | Материалы под NDA, непубличная отчетность клиентов |
| Ваши чувствительные реквизиты | Паспортные данные, реквизиты счетов |

Для деловых данных в API есть режим Zero Data Retention: запросы не сохраняются. Это снижает риск, но не меняет юрисдикцию.

## Риски агента, а не только чата

Kimi Work не просто отвечает, он действует. Отсюда три отдельных риска:

1. Браузерный агент WebBridge работает в вашем настоящем браузере с вашими входами в аккаунты. Почта, банк и рабочие сервисы технически ему доступны. Не давайте задачи, которые касаются банковских страниц и платежей.
2. Агенты склонны выполнять задачу «вслепую», не распознавая рискованные действия. Режим «спрашивать перед действием» должен оставаться включенным.
3. Задачи по расписанию работают без вашего взгляда. Проверяйте итоги первых запусков вручную, прежде чем доверять расписание.

## Правила безопасной работы

1. Отдельная папка для агента. Не подключайте к Kimi Work все документы. Создайте рабочую папку и кладите туда только то, что нужно для задачи.
2. Без секретов в запросах. Ключи и пароли не отправляются в чат ни при каких условиях. Если нужно показать ошибку, замажьте секретную часть.
3. «Спрашивать перед действием» всегда включен.
4. Проверка фактов. По независимым замерам доля неточных утверждений у модели снизилась, но остается заметной: Artificial Analysis измерил 44 процента на своем тесте галлюцинаций. Любой факт, от которого зависит решение, проверяется по источнику.
5. Осторожность с цифрами вендора. Бенчмарки от самой Moonshot это материалы производителя, а не независимая проверка.
6. Резервный канал. Доступ к сайту из России бывает нестабилен у части провайдеров. Для критичных процессов держите запасной способ доступа и запасной инструмент, см. [12-план б на случай блокировки](12-%D0%BF%D0%BB%D0%B0%D0%BD%20%D0%B1%20%D0%BD%D0%B0%20%D1%81%D0%BB%D1%83%D1%87%D0%B0%D0%B9%20%D0%B1%D0%BB%D0%BE%D0%BA%D0%B8%D1%80%D0%BE%D0%B2%D0%BA%D0%B8.md).

## Чек-лист перед доверенной задачей

1. Задача не содержит секретов и чужих персональных данных.
2. Агент подключен только к нужной папке.
3. Режим подтверждения действий включен.
4. Первый запуск сделан под наблюдением.
5. Есть способ отменить результат: копия файлов, отдельная ветка, черновик.
